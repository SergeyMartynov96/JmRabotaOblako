# Утренние показатели

Отдельный модуль; не импортирует и не запускает код заявок. Работает только через
GitHub Actions. Закупочные листы и таблицы топов доступны ему только для чтения.
Пишет только восемь согласованных ячеек в блоке текущей недели «Выручки» каждого
филиала: выручка сверху/снизу, сумма списаний, общий % снизу, три топа, закуп факт.
Не создаёт даты/недели, не меняет планы, оформление, формулы или прочие показатели.

Каждый запуск обрабатывает только вчера по Asia/Yekaterinburg. Дату задним числом
указать нельзя. Запуск, созданный в другой календарный день, отклоняется. Заполненная
ячейка (включая 0, прочерк и формулу) сохраняется; повторный запуск её не обновляет.
Перед записью проверяются полная дата, недельный заголовок и дата нижнего блока,
а затем пустота самой ячейки. Запись перечитывается через формульную строку.

Источники:

- СУ, отчёт по выручке, сутки, вчера–вчера, бренд Все; точное название филиала,
  строка «Итоговая выручка», колонка «Итоги». Параметр выбора `department[]`.
  Один общий отчёт по трём магазинам, ожидание до 10 минут без повторного запроса.
- СУ, отчёт по актам списания, вчера–вчера, один филиал, без ограничений статуса/
  причины; сумма себестоимости документов. Этот отчёт принимает фильтры GET,
  несмотря на POST в HTML формы. Дублировать footer в сумму нельзя.
- Топы: актуальная вкладка, три блока сверху вниз — готовая, десерты, Япония.
  Вторая колонка нужной даты, исходный итог наличия снизу; результат 100 − итог.
  Если все продуктовые ячейки пустые, результат «—», даже если формула итога 0.
  Явные нули → 100 отсутствия. У АВ12 общий заголовок дат для всех блоков.
- Закупочные листы: итог еды + Японии вчерашней даты. Десерты исключены.
  Г34 подписывает итог «СУММА ГОТОВАЯ+ЯПОНИЯ», М42 — «Итого готовая еда».
- Суммы округляются до рубля HALF_UP. % списаний берётся из видимого результата
  существующей верхней формулы, с её точностью; М42 внизу имеет процентный формат,
  АВ12/Г34 — число процентных пунктов. Формулы не заменяются.

Пустой корректный отчёт/нет даты источника/незаполненные топы → «—», без ошибки и
письма, без последующих догрузок. Сбой входа/сети/структуры/даты назначения/записи →
ошибка Actions и штатное уведомление GitHub о сбое. Остальные доступные показатели
и филиалы обрабатываются. Успешных писем модуль не отправляет.

Ручная проверка: workflow `daily-metrics.yml`, operation=preview, branch=М42/all.
Preview ничего не пишет. Apply разрешён только для вчерашней даты текущего запуска.
В журнале только счётчики/причины ошибок; суммы и исходные документы не публикуются.
Расписание включается после облачной проверки. Локальный исполнитель выключен.

Для будущих УВ/OSA/накладных добавляются отдельные источники/целевые ячейки в этом
модуле. Код автоматизации заявок для этого менять не требуется.
